Installation

Up and running in two minutes.

Download the repository ZIP and run the installer for your OS—no Git required. Or drag the 6 folders from plugins/ straight into your GIMP plug-ins directory.

Download Suite ZIP
  1. 1. Download and extract the Suite ZIP anywhere.
  2. 2. Double-click install.bat to copy all 6 plugins into %APPDATA%\GIMP\3.2\plug-ins\.
  3. 3. Restart GIMP 3.
# Optional (with Git):
git clone https://github.com/bunnywaffle/gimp-pro-suite.git && cd gimp-pro-suite && .\install.bat

Supports both native (~/.config/GIMP/3.2/plug-ins/) and Flatpak (~/.var/app/org.gimp.GIMP/config/GIMP/3.2/plug-ins/). When both exist, install.sh prompts you to choose.

chmod +x install.sh && ./install.sh --flatpak
# Flatpak AI worker venv (sam3_select):
flatpak run --command=python3 org.gimp.GIMP -m venv ~/.var/app/org.gimp.GIMP/data/sam3-venv ~/.var/app/org.gimp.GIMP/data/sam3-venv/bin/pip install torch torchvision transformers pillow numpy opencv-python-headless ultralytics flatpak override --user --env=VIRTUAL_ENV=/var/data/sam3-venv org.gimp.GIMP

FAQ

Common questions

What if I do not have Git installed?

Git is not required. Download the Suite ZIP, extract it, and double-click install.bat (Windows) or run ./install.sh (Linux/macOS). You can also drag the 6 folders inside plugins/ directly into your GIMP plug-ins directory.

Do I need to install all 6 plugins?

No. Each plugin is standalone and does not depend on the others. You can copy only the folders you want from plugins/.

Does this work with GIMP 2.10?

No. These plugins target GIMP 3.0 / 3.2+ and its Python 3 GObject Introspection API and GEGL non-destructive editing engine.

Does SAM 3 Interactive Select run offline?

Yes. All inference runs locally on your CPU or GPU. On the first AI run, SAM 2 tiny (~156 MB) downloads once into sam3_select/models/; after that, no network connection is needed.
