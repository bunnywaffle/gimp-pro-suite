FAQ

Do I need to install all 6? ⌄

No. Each plugin is standalone. Install only what you need — they don’t depend on each other.

Will this work with GIMP 2.10? ⌄

No — these target GIMP 3.0/3.2’s modern Python 3 API and non-destructive engine. Upgrade is free.

Are they really Photoshop-identical? ⌄

Presets, sliders, hotkeys and UI mirror Photoshop & Illustrator. The engines (GEGL, Meta SAM, PatchMatch, graph-cut) are production-grade.

Is my work private? ⌄

100% offline. No cloud, no telemetry, no account. Your images and AI models run locally on your machine.
